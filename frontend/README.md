# MeloPet 前端（核心链路 + 动态桌宠）

这是依据专业 PRD v1.0.0、技术适配声明 v1.0.0、第一阶段核心链路技术开发文档 v1.0.0，以及 `import-playlist.html` 参考模板实现的产品前端。

## 已实现

- 一次多选或拖入最多 1,000 首本地音频，支持 MP3、M4A、FLAC、WAV、OGG 等常见格式。
- 浏览器在本机读取歌名、艺人、专辑、时长、曲风、情绪和 BPM 标签；标签不足时，对歌曲头部、中段和尾部做快速声学特征提取。
- 标签读取与特征提取使用 2～4 路自适应并发；结果按音频内容指纹缓存在 IndexedDB，再次导入同一文件可直接复用。
- 音频原文件不上传，后端只接收必要的歌曲元数据及归一化数值特征（能量、频谱亮度、动态、节拍和节拍置信度）。
- 匿名 capability 身份、同源 API 转发与写请求幂等键。
- 字段自动整理、有效/无效/重复计数、前 20 行规范化预览。
- 异步任务进度、超时提示、取消、重试与刷新后恢复。
- 总和为 100% 的情绪画像、`UNKNOWN`、低样本/低信号提示。
- 逐曲改情绪、排除、重新纳入、恢复自动判断、版本化保存和画像确认。
- 3 个真实后端渲染候选、规则来源解释、安全模板/开发素材标记和候选选择。
- 授权状态、撤回授权、异步删除和删除状态恢复。
- 键盘焦点、文本缩放可滚动布局和减少动态效果支持。

桌宠页已接入桌面激活与四状态控制；桌面进程支持持续逐帧动画、跨应用驻留、拖拽、点击反馈、托盘菜单和可选登录自启动。

## 本地启动

先启动后端 API 和 Worker：

```bash
cd ../backend
./scripts/start-validation.sh
```

再开一个终端启动前端：

```bash
cd ../frontend
npm install
npm run dev
```

浏览器打开 `http://127.0.0.1:4173/`。

前端默认通过服务端同源代理连接 `http://127.0.0.1:8010`。如后端地址不同，复制 `.env.example` 为 `.env.local` 并修改 `MELOPET_API_ORIGIN`；该变量只供前端服务端使用。

## 验证

```bash
npm run check
npm audit
```

匿名 capability token 与工作流标识保存在当前浏览器的 `localStorage`，用于刷新恢复。音频文件和导入前的本地列表不会存入浏览器持久化存储；IndexedDB 仅保存不可播放的数值特征和内容指纹。
