# MeloPet 动态桌面宠物

把 M1 已生成的音灵做成真正驻留桌面的桌宠（透明置顶窗口）。

## 启动

首次会自动在 `.validation/desktop-pet-venv` 构建当前电脑可用的 PySide6 环境。

macOS 可双击 `启动桌宠.command`，或在终端执行：

```bash
cd "本目录"
./run-pet.sh
```

Windows 可双击 `启动桌宠.cmd`；脚本优先使用 Python Launcher，并以 `pythonw.exe` 启动，避免常驻控制台窗口。

启动后可关闭终端窗口，桌宠会继续运行。
缩小、最小化浏览器或切换到其他应用时，桌宠仍会驻留桌面；只有手动选择“隐藏桌宠”、执行隐藏命令或退出时才会消失。

## 操作

| 操作 | 效果 |
|---|---|
| 左键拖拽 | 移动桌宠位置（自动记住位置） |
| 左键单击 | 切换动作：待机 → 聆听 → 跳舞 → 睡觉，并弹出对应台词 |
| 右键 | 切换动作、自动轮播、低动态、置顶、登录自启动、隐藏或退出 |
| 菜单栏图标 | 桌宠隐藏后仍可显示、切换状态或退出 |

网页的四个动作卡片也可直接推送状态。桌宠运行时还可用根目录命令：

```bash
python3 pet.py --state dance
python3 pet.py --auto-cycle off
python3 pet.py --visibility hide
```

## 停止

- 右键桌宠 →「退出桌宠」；或
- 终端执行：`pkill -f "desktop-pet/.*pet.py"`

## 说明

- 桌宠读取后端已选候选的物种、配色、配饰、情绪和台词，以 30 FPS 程序化渲染，不执行下载脚本。
- 待机状态也会持续上下漂浮、轻摆、呼吸并旋转环境光点；聆听/跳舞/睡觉使用各自不同的位移、旋转、缩放和特效。低动态模式由用户主动开启，开启后降为 10 FPS。
- 位置、当前状态和设置保存在 `pet-state.json`；状态推送使用本地原子文件 `pet-command.json`；日志在 `pet.log`。
- 默认不开启登录自启动，需要用户在右键/托盘菜单中主动开启。macOS 使用用户级 LaunchAgent，Windows 使用当前用户 HKCU Run，不要求管理员权限。
- macOS 使用“应用失焦仍显示”的工具窗口属性；Windows 使用独立透明置顶工具窗口。两端还会拦截非用户发起的隐藏，因此浏览器状态不会控制桌宠显隐。
