## 不能伪装成“已验收”的外部项

以下不是遗留的后端业务代码，而是 PRD 明确规定必须由 M0 Owner/合同/真实资源关闭的交付前置：

- 真实模型：未提供经批准的 provider、model ID、API Key、处理地域、费率和预算，因此真实模型 E2E/黄金集继续标记“待验收”。
- 真实音乐信号来源：没有已批准的数据源与字段/地域/缓存合同；Spotify 依 PRD 保持阻断，后端对未批准 provider fail closed。
- 生产资产：当前是明确带 `DEV ONLY` 水印的开发占位资产，不能替代授权、签名、真实 renderer bundle 与视觉验收。
- 生产基础设施：服务地域、生产数据库/对象存储、容量与删除 SLA 尚未冻结；开发环境使用 SQLite + 本地对象存储，`APP_ENV=production` 会主动拒绝这些开发配置。

因此，准确状态是：**M1 后端可开发/可联调代码已完成；生产放行与真实模型/来源/资产验收待外部条件齐备后执行。** `/readyz` 会持续如实返回这一边界。
